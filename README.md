## 🌟 Highlights & Features

- **🌐 Live Vercel Deployment**: Zero build-step static deployment with instant global CDN delivery at [personal-portfolioag.vercel.app](https://personal-portfolioag.vercel.app/).
- **⚡ Zero Frameworks / Zero Dependencies**: Pure static web standards. No React, Next.js, TypeScript, or npm build required.
- **🎨 Multi-Theme Engine**: Seamless switching between **Dark (🌑)**, **Light (☀️)**, and **Warm Reader (☕)** themes with persistent state in `localStorage` and zero theme flash.
- **🛰️ Tactical Neural AI HUD**: Holographic HUD activated via `CMD+K` / `Ctrl+K` or the central AI Core button, featuring real-time telemetry streaming and rapid keyboard navigation.
- **📊 Interactive Expertise Radar**: Fully responsive SVG radar visualization showcasing machine learning and software engineering capabilities with dynamic tooltip readouts.
- **🔍 Filterable Project Showcase**: Live multi-category filter and instant search across featured AI/ML engineering projects.
- **📖 Dynamic GitHub README Inspector**: In-portfolio live Markdown reader fetching project documentation directly from GitHub repositories.
- **🎓 Comprehensive About & Experience**: Interactive tabs covering Executive Summary, Experience, Core Competencies, Education & Certifications, and integrated PDF resume viewer.
- **✉️ Interactive Contact & Newsletter**: Fully responsive contact forms and newsletter subscription with client-side validation.

## 💻 Local Development

To run or preview the portfolio locally, open `index.html` directly in your browser or run a lightweight local server:

```bash
# Using Python
python3 -m http.server 8000

# Or using npx
npx serve .
```
Then visit `http://localhost:8000`.
